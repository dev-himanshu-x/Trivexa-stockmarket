# Trivexa Markets

A stock market dashboard built with Next.js. Shows a portfolio overview, a
searchable watchlist, and some basic analytics charts. All the stock data is
fake — generated with a seeded random number generator so it looks the same
every time you load the page.

## Getting started

You'll need Node.js installed. Then:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## What's in here

- `app/` – the main page and root layout
- `components/` – the dashboard UI (sidebar, tables, charts, search, etc.)
- `lib/` – fake data generation and the logic that crunches it into stats

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – build for production
- `npm start` – run the production build
- `npm run lint` – run ESLint

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Recharts for the charts
- lucide-react for icons
